Simple Bank 🏦

A simple banking backend written in Go, using PostgreSQL, sqlc, and database transactions.
This project demonstrates clean architecture, concurrent-safe money transfers, and thorough unit testing.

✨ Features

✅ Account management (CRUD)

✅ Entries & transfers

✅ Safe money transfer with SQL transactions

✅ Deadlock-free concurrent transfers

✅ SQL code generation with sqlc

✅ Unit tests with testify

✅ PostgreSQL migrations

🛠 Tech Stack

Go (1.20+)

PostgreSQL

sqlc

Docker & Docker Compose

testify
